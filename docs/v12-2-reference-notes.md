# V12.2 reference study — interaction principles

Reference studied: `https://wearebrand.io/`

The implementation study identified a layered artistic-parallax approach rather than ordinary section scrolling. The public reference exposes a Slider Revolution artistic-parallax module with multiple independent image layers, background plates, foreground subjects and atmosphere assets. The useful principle is depth choreography: different visual planes move at different rates while typography and scene composition change as one experience.

V12.2 deliberately does **not** copy reference code, assets, copy or layout. It translates the interaction principles into an original native-JavaScript/CSS architecture using Banuja Disanayaka's own photography, portraits, project imagery, brand language and semantic portfolio content.

The translation rules are:

- one persistent visual exhibition stage;
- multiple independently composed chapter worlds;
- layered media planes rather than one decorative background;
- cross-scene presence overlap so one world visually transforms into the next;
- pointer depth on desktop only;
- semantic HTML remains the accessible/SEO source of truth;
- lightweight mobile/reduced-motion path;
- no dependency on Slider Revolution, WordPress, WebGL or third-party motion runtime for this pass.
