THE PROBLEM

A real starting point.

When orders arrive through retail, wholesale and delivery channels, the difficult part is keeping the whole operation aligned. An order is only useful when the people preparing, checking and handing it over share the same picture.

THE APPROACH

Make the relationships clear.

I brought the perspective of an outlet PIC and ordering administrator into the product: organise the work around what the team needs to do next, then connect orders with production and stock information.

DESIGN DECISIONS

01

One operational workspace

The React application brings order handling and production workflows together, with Firebase supporting shared application data.

02

A workflow people recognise

Product and recipe data support the planning process. The interface follows the language of the operation rather than a generic project board.

03

Documentation alongside the product

The repository includes an application user guide and visual checks. Both matter when a tool is handed over to a busy team.

Where it stands

This case study describes the implemented architecture and the workflow behind it. It does not claim measured time savings, verified adoption figures or an independent production audit.

Source basis: Reviewed application source, product and recipe data structure, the V8 user guide, Netlify function and visual test files.
